### 10/3

ゴールキック分析の方針を決めた。

- **設定**
  - コートを6×5のグリッドに分割し、攻撃方向は左→右にそろえる。
  - ゴールキックが最初に触られた位置をグリッド g とする。
  - k アクション後の状態を4カテゴリに分ける（k=3, 5, 10 で結果が大きく変わらないか確認する）。

    | カテゴリ | 状態 | 点数（仮） |
    | --- | --- | --- |
    | c1 | 敵陣で保持（最良） | 1 |
    | c2 | 自陣で保持（必要なら自陣を細分化） | 0.5 |
    | c3 | 敵陣でロスト | 0 |
    | c4 | 自陣でロスト（最悪） | -1 |

- **ロストの定義**
  - k アクション以内に一度でも相手がボールを保持したらロスト（その後奪い返してもロスト扱い）。
  - k アクションより前にプレーが切れた場合のルールを決めておく。
    - シュート・ゴール → c1 扱い
    - タッチラインを割った → スローインの権利で判定
    - ファウル → 要検討

- **出力（両方出す）**
  1. カテゴリ別の確率マップ：各グリッドで c1〜c4 になる確率。
  2. スコアマップ：カテゴリの点数で期待値をとる。U(g) = Σ（カテゴリ c の点数 × グリッド g で c になる確率）
  - 「どこに蹴るのが良いか」は 2 で判断し、「なぜそのスコアか」は 1 で説明する。

- **注意点**
  - 同じスコアでも中身が違うことがある（例：「半分は敵陣保持・半分は自陣ロスト」と「毎回敵陣でロスト」はどちらも 0）。
  - 点数は仮置きなので、点数を変えても順位が入れ替わらないか確認する。

- **余力があれば**
  - 相手のプレス強度などで分けて比較する（位置の差か、状況の差かを切り分ける）。
  - サンプルが少ないグリッドは値がブレやすいので、必要なら全体平均に寄せる補正をする。

### 10/4

10/3 の方針を以下のように更新した。

- **アクション数**
  - k=7 に固定する（ルーズボールは7アクションあたりでどちらのボールかが確定する、という経験則から）。10/3 の「k=3, 5, 10 で比較」から変更。

- **カテゴリ**
  - 敵陣／自陣の区分をより細かくする（グリッド単位でもよい）。先行研究によると、センターラインを越えるかどうかで話が大きく変わるため。
  - シュートまで行った場合の別カテゴリを追加する（シュートまで行ったならロストではない、という意見から）。
  - カテゴリは細かめに作っておき、後から統合すればよい。

- **ロストの定義（10/3 から変更）**
  - 相手が3アクション以上した時点でロストとする（その後、最終アクションで自チームが保持していても、それはインターセプトしただけと考える）。10/3 の「一度でも相手が保持したらロスト」から変更。
  - 相手のGKまでボールが行った場合はロストとする（その時点でアクションが切れると考えられるため）。

- **プレーが切れた場合（スローイン・ファウル）**
  - 自チームスタートで再開 → そこでアクションを区切り、プラス評価（保持しているとみなす）。
  - 相手スタートで再開 → ロスト。

- **出力**
  - ボールが落ちた位置を変数として、ロストする確率を出す。
  - ボールが落ちた位置のうち、ロストした位置をマッピングする。
  - 確率マップを出した後、最終的にカテゴリごとの期待値（確率 × 重み付けしたスコア）を出す。

### 10/6

判定をアクション数ベースから時間ベースに変更した。10/3・10/4 の「k アクション後の状態」と「相手が3アクション以上でロスト」は廃止。

- **保持の決着**
  - どちらかのチームがボールを確立してから T 秒以上、相手に保持を確立されなかった時点で、そのチームの保持として決着する（自チームなら保持、相手ならロスト）。T は両方で同じ値を使う。
  - 時計の起点は、最終的にそのチームのコントロールにつながった一連のタッチのうち、最初のタッチの時刻。
  - 相手の一瞬のタッチ（コントロールにつながらないもの）では、保持は切り替わらない。

- **即決着するケース**
  - ボールが外に出た場合（直接出た、T 秒経つ前に出た、ファウルで止まった）は、再開でボールをスタートしたチームの保持で決着する。
  - ファウルは `Foul Committed` ではなく、実際に `Free Kick` で再開したかどうかで判定する（アドバンテージに対応するため）。
  - 相手GKがボールに触れた時点で即ロスト。

- **「時計を始めるタッチ」に含めるイベント**
  - `Pass`, `Clearance`, `Block`, `Interception`, `Miscontrol`, `Shot`, `Carry`, `Dribble` は条件なし。
  - `Ball Receipt*` と `Ball Recovery` は成功したもの、`Duel` は Tackle で勝ったもの、`50/50` は Won のもの。
  - `Pressure`, `Dribbled Past`, Aerial Lost, 失敗した受け・回収は含めない。`Dispossessed` は保留（まずは含めない）。
  - 成功を表す列は成功時に NaN になるので、`isna()` で判定する。

- **カテゴリ**
  - 敵陣保持 / 自陣保持 / ロスト（敵陣）/ ロスト（自陣）/ シュート / 直接タッチ（誰も触らず外に出たもの）。
  - 敵陣と自陣の境界は x=60。相手チームのイベントの座標は (120-x, 80-y) で反転する。
  - 判定の優先順位：直接タッチ → 即決着 → シュート → T 秒の保持決着。
  - ロストの位置は、相手の保持が始まった位置。保持とロストは同じ粒度で位置を記録する。

- **集計**
  - グリッドごとのカテゴリ確率を、ディリクレ多項モデルの経験ベイズで縮小推定する（サンプルが少ないグリッドへの対応）。
  - カテゴリ別の内訳と、期待効用スコア U(g) = Σ（重み × 確率）の両方を出す。

- **まだ決まっていないこと**
  - T の値（5, 10, 15 秒で比較する）。
  - 保持時の位置の取り方（保持区間の開始位置か、T 秒に達した時点の位置か）。
  - 相手のシュート（カウンター）をロストに含めるか、別カテゴリにするか。
  - PK になった場合の扱い。
  - 決着前にハーフが終わった場合（仮：除外）。
  - 相手GKが弾いたボールを自チームが拾った場合もロストのままでよいか（現状はロスト）。
  - デッドボールの時間を T に含めるか。
  - 2019/20 のルール改正の前後のシーズンを混ぜるか。
  - 「コントロールにつながった」をデータ上でどう判定するか（例：同じチームのタッチが何回続いたら確立とみなすか）。
  - カテゴリごとの重み（シュートと直接タッチの点数が未定）。

- **既知のリスク**
  - 選択バイアス（プレス強度や試合状況によって蹴る場所が変わる）。
  - 固定の時間ウィンドウは、ショートビルドアップに不利に働きうる。

### 10/7

10/6 の方針を一部変更した。

- **相手の一瞬のタッチの扱い（10/6 から変更）**
  - 相手が一瞬でもタッチしたら、その時点で保持は相手に切り替わる（コントロールにつながったかどうかは問わない）。10/6 の「相手の一瞬のタッチでは保持は切り替わらない」から変更。
  - 例：A が保持中に B がブロックし、A が拾う → ブロックの時点で B に切り替わり、拾った時点でまた A に切り替わる。A の時計は拾った時刻からやり直しになる。
  - 例：A が保持中に B がブロックし、B が拾う → B の時計はブロックの時刻から始まる（ここは 10/6 と同じ）。
  - これにより、10/6 の未決事項のうち「コントロールにつながった」をデータ上でどう判定するか、は不要になった。

- **デッドボールの時間**
  - T 秒に数えない。どちらのチームも T 秒以上保持できないままプレーが止まったら、再開でスローインなどをするチームが「保持」のラベルを持つ。10/6 の未決事項から外した。

- **ゴールキック自体の扱い**
  - ゴールキック自体はタッチに数えない。時計は、ゴールキックの後に最初に触られた時刻から始まる（相手GKが触った場合は即ロストのまま）。

- **誰も触らないままファウルで止まった場合**
  - 直接タッチにはせず、再開したチームの保持で決着する。
