# ゴールキック後のロスト位置の定義

## 目的

ゴールキック後にボールをロストした位置を記録し、最初に触られた位置（着地点）との関係を調べる。
## 保持・ロスト

- ゴールキックを蹴った時点で「保持」のラベルを付ける。自チームが保持を続けても追跡を終了しない。
- 相手の連続保持時間を **T = 2 秒（暫定）** とする。
- 相手の最初のタッチから時計を開始する。自チームがタッチをしたらリセットし、次の相手タッチから数え直す。
- 相手の時計の起点から T 秒以上経過した後、相手の最初の対象タッチで「ロスト」を確定する。
- T 秒経過後でも、相手の次のタッチより先に自チームが触れたらロストを確定しない。
- この時間判定でのロスト位置は、相手の連続保持が始まった最初のアクションの、1つ前の自チームのアクションの最終位置とする。自チームの対象タッチが0回なら、その連続保持を開始した相手の対象アクションの `location` を使う。判定確定時刻と、位置の参照元は分けて記録する。
- 相手の時計を数え直した場合は、新しい連続保持の開始を基準に位置の参照元も選び直す。
- 自チームの「アクション」は下記の対象タッチに限定する。最終位置は `Pass` では `pass_end_location`、`Carry` では `carry_end_location`、それ以外は `location` を使う。終点が欠損していても開始位置で補完しない。
- 位置の参照元イベントIDも記録する。自チームの対象タッチが0回でも、ゴールキックの `pass_end_location` では補完しない。

## 元の定義書から引き継ぐ判定

### タッチ

ゴールキック自体を除き、次のイベントを数える。一瞬のタッチでも時計を切り替える。

| イベント | 条件 |
| --- | --- |
| `Pass`, `Clearance`, `Block`, `Interception`, `Miscontrol`, `Shot`, `Carry`, `Dribble` | 条件なし |
| `Ball Receipt*` | `ball_receipt_outcome` が NaN（成功） |
| `Ball Recovery` | `ball_recovery_recovery_failure` が NaN（成功） |
| `Duel` | `duel_type == "Tackle"`。勝敗は問わない |
| `50/50` | `50_50["outcome"]["name"]` が `Won` / `Success To Team` / `Success To Opposition` |
| `Goal Keeper` | 下表の「通常タッチ」に該当 |

上記以外は数えない（失敗した受け・回収、空中戦の敗者、`Pressure`、`Dispossessed`、ファウルなど）。成功の NaN は `isna()` で判定する。

### シュート・オウンゴール

- 流れの中のシュート（`shot_type == "Open Play"`）で終了する。自チームによるシュートなら保持、相手によるシュートならロストとし、`shot=True` とシュート位置を記録する。
- オウンゴールで終了する。自チームの得点なら保持・`own_goal="for"`、失点ならロスト・`own_goal="against"`。位置はそれぞれ `Own Goal For` / `Own Goal Against` の位置。

### プレー停止・再開

- 外に出た・ファウル・オフサイドなどは、再開チームで終了する。自チームなら保持、相手ならロスト。位置は再開位置。
- 再開は `pass_type` が `Throw-in` / `Free Kick` / `Corner` / `Goal Kick` / `Kick Off`、`shot_type` が `Free Kick` / `Penalty` / `Corner`、または `Referee Ball-Drop`。
- `Recovery` / `Interception` のパスは再開ではない。ファウルイベントだけでは終了しない（アドバンテージに対応）。
- ドロップボールは、その後の最初のタッチのチームで判定し、ドロップ位置を記録する。
- 再開がシュートでも `shot=False`。PK（`shot_type == "Penalty"`）は、自チームの再開なら `penalty="won"`、相手なら `penalty="conceded"`。
- 誰も触らず外に出た場合は「ダイレクトアウト」として別集計する。ゴールキックの `pass_outcome == "Out"` で判定し、ロスト位置の集計には含めない。

### GKの確保・弾き出し

`type == "Goal Keeper"` を次のとおり扱う。

| `goalkeeper_type` | `goalkeeper_outcome`の値のうち確保（即終了）として扱う値 | `goalkeeper_outcome`の値のうち通常タッチとして扱う値 |
| --- | --- | --- |
| `Collected` | `Success` / `Collected Twice` | なし |
| `Punch` | なし | `In Play Safe` / `In Play Danger` / `Punched out` |
| `Keeper Sweeper` | `Claim` | `Clear` |
| `Smother` | `Won` | `Success In Play` / `Lost In Play` / `Lost Out` |

- 自チームGKの確保は「保持」で終了し、そのGKイベントの位置を記録する。
- 自チームの対象タッチ後に相手GKが確保した場合は「ロスト」で終了し、直前の自チームの対象アクションの最終位置を記録する。
- 両チームの対象タッチが0回のまま相手GKが最初に確保した場合は「相手GK直接確保」として別集計する。着地点はその確保イベントの `location` とし、ロスト位置の集計には含めない。GKの確保自体は対象タッチに数えない。
- 自チームの対象タッチが0回で相手の対象タッチがある場合は、T秒ルールに従い、その連続保持を開始した相手の対象アクションの `location` をロスト位置とする。
- 通常タッチは時計の開始・リセットだけ行う。外に出た場合は再開チームで終了する。
- `Fail` は接触が不明なので無視する。表にないGKイベントは判定に使わない。足での `Pass` / `Carry` は通常の対象タッチ。

### 観測期間・優先順位

- 観測期間の上限は設けない。自チームの保持時間だけでは終了せず、ロストまで追跡する。
- ただし、上記のシュート・オウンゴール・再開・GK確保・ダイレクトアウトでは、その規則で終了する。自チームのシュート・再開・GK確保は「保持」で終了する。

### 時刻・座標・着地点

- `timestamp` を `period` ごとに秒へ変換し、`period`・`index` 順に処理する。時刻順には並べ替えず、直前より時刻が戻る行は無視する。
- 終了前にハーフが終わった場合は除外する。
- 全位置はゴールキックを蹴ったチーム視点。相手の座標は `(120-x, 80-y)` に反転する。
- ピッチは120×80、グリッドは6×5（幅20×16）。`x >= 60` は敵陣、それ未満は自陣。図の攻撃方向は下から上。
- 着地点は最初の対象タッチの位置。誰も触らず外に出たら再開位置、ファウルなら `Foul Committed` の位置（なければ `Free Kick` の再開位置）。それ以外は欠損として件数を残す。
- 時間判定・相手GK確保でのロスト位置は、上記の対象タッチの有無による規則に従う。それ以外の終了位置は各判定の規則に従う。

## 記録

- ゴールキックの識別情報、着地点、結果ラベル、決着時刻・位置、判定理由を記録する。
- `shot` は通常 `False`、`penalty`・`own_goal` は該当しなければ空欄とする。
- ロスト以外の終了結果も残し、ロスト件数・割合の分母を確認できるようにする。
- ゴールキック後から判定終了までの自チーム・相手チームの対象タッチ回数を記録する。ゴールキック自体とGKの確保は数えない。
- 「相手GK直接確保」と「ダイレクトアウト」は、それぞれ通常のロストと分けて件数を記録する。

## 表示（データの確認）

判定結果のCSVを読み込み、napariで2つのヒートマップを左右に表示する。判定・CSV保存と可視化の処理は分ける。

| 表示 | 内容 |
| --- | --- |
| 左側 | ゴールキックの着地点の件数をグリッドごとに表示する |
| 右側 | 左側で選んだ着地点グリッドから、各グリッドが最終位置になる確率を表示する |
| 一番右の別集計欄 | 相手GK直接確保・ダイレクトアウトの件数を、選択グリッド内と全体に分けて表示する |

- 左側のグリッドをクリックすると、選択枠を表示し、右側を更新する。
- 別集計欄もクリックに連動して更新する。全体件数には着地点が欠損・範囲外のデータも含める。
- 両側とも6×5グリッド、同じ座標・攻撃方向（下から上）で表示する。最終位置は各判定で定めた記録位置を使う。
- 左側は着地点が有効な全件を数える。右側は選択した着地点のうち、保持・ロストで最終位置も有効なデータを集計する。「相手GK直接確保」と「ダイレクトアウト」は右側の分布・確率の分母から外し、それぞれ別に件数を表示する。
- 右側の確率は「各最終位置グリッドの件数 ÷ 選択した着地点グリッドの集計対象件数」とする。合計は100%になる。
- グリッドID、件数、右側の実際の確率（%）、色の凡例を確認できるようにする。右側の色は選択によらない固定尺度とし、0%を白、50%以上を赤（1.0）とする。色の強さは `min(確率 / 50%, 1.0)` で計算する。
- 選択した着地点の総件数、右側の集計対象件数、相手GK直接確保・ダイレクトアウト・欠損・除外の件数を表示し、分母を確認できるようにする。
- 集計対象が0件なら「データなし」と表示する。確率0%と区別し、前の選択結果を残さない。
- 着地点・最終位置の欠損や範囲外の座標を、任意のグリッドへ補完しない。着地点を割り当てられない件数は別に表示する。
